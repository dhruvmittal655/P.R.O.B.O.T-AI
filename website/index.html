Desktop Research Library & Offline Study Assistant

ProBot AI is an open-source Python desktop application that searches Wikipedia, aggregates multi-source tutorial packs, caches articles offline in a local SQLite database, extracts structured study notes, and answers context-based questions using local Ollama language models.

      Core Capabilities

      What ProBot AI Does

      Designed to solve the fragmentation of researching across multiple browser tabs, unorganized notes, and missing internet connectivity.

      Wikipedia Ingestion

      Searches Wikipedia through OpenSearch and Action APIs, retrieving complete article text and saving high-resolution thumbnails locally into the images/ cache.

      Offline SQLite Library

      All saved articles, research packs, view histories, and favorites are stored locally in data/knowledge.db. When disconnected from the internet, search falls back seamlessly to local database records.

      Study Notes Generation

      Extracts core summary paragraphs, strips footnote brackets, filters common stop words, identifies high-frequency topic terminology, and formats review questions for exam preparation.

      Private Local AI Assistant

      Interfaces directly with Ollama running the lightweight phi3:mini model. Q&A runs entirely on your local CPU or GPU without sending your research data or queries to external third parties.

      Multi-Source Aggregation

      Assembles research packs from Wikipedia, Britannica, GeeksforGeeks, and academic arXiv repositories based on topic keywords to compile a multi-perspective briefing document.

      Document Export

      Exports any article, extracted study pack, or research collection directly into formatted PDF documents (via ReportLab) or clean plain-text files for offline study.

      Architecture

      Local Storage & Database Design

      ProBot AI follows a local-first design philosophy. Everything is saved in predictable files on your machine.

      Path / Table Storage Engine Purpose & Stored Information
      data/knowledge.db → articles SQLite 3 Stores article title, full text, summary, topic, source URL, word count, view count, favorite status, and created timestamp.
      data/knowledge.db → history SQLite 3 Logs search queries, clicked articles, and timestamps for chronological history navigation.
      data/knowledge.db → research_sources SQLite 3 Stores parent research pack metadata, aggregate topics, and creation dates.
      data/knowledge.db → research_chunks SQLite 3 Contains chunked text snippets extracted from Wikipedia, arXiv, and tutorial websites.
      images/ Filesystem Cache Stores downloaded thumbnail images keyed by article name for offline visual rendering.
      Installation

      Getting Started Locally

      ProBot AI requires Python 3.10+ and standard build tools. Follow these steps to set up the environment and run the application.

      1. Install Python Dependencies

      Create a virtual environment if desired, then install all project requirements:

      Terminal (PowerShell / Bash) 
      pip install -r requirements.txt

      2. Download the SpaCy Language Model

      SpaCy uses the small English pipeline for entity extraction and linguistic analysis:

      Terminal 
      python -m spacy download en_core_web_sm

      3. Setup Ollama (For Local AI Chat)

      Install Ollama, ensure the service is running, and pull the lightweight phi3:mini model:

      Terminal 
      ollama pull phi3:mini

      4. Run Application

      Launch the CustomTkinter graphical desktop interface:

      Terminal 
      python main.py
      FAQ

      Frequently Asked Questions

      Does ProBot AI work completely without an internet connection?
      Yes. When offline, ProBot AI falls back to articles and research chunks already cached in data/knowledge.db. It supports case-insensitive exact matching and partial title searches on saved documents. However, searching for brand-new Wikipedia articles or downloading arXiv PDFs requires an active internet connection.
      Can I run the application without installing Ollama?
      Yes. All core features—Wikipedia search, article caching, offline SQLite library, extractive study notes generator, and PDF export—function independently. The local AI chat tab is the only component that requires an active Ollama instance with phi3:mini.
      Where are my downloaded articles and images saved?
      Articles and research metadata are stored inside data/knowledge.db as an SQLite database. Downloaded thumbnails are saved in the images/ directory. Deleting an article inside the app removes it from the database table; image files may remain in the cache until cleaned manually.
      What graphical framework is used for the desktop interface?
      The user interface is built using CustomTkinter, an extension of Python's standard Tkinter that provides modern dark/light mode widgets, high-DPI scaling, and consistent cross-platform styling across Windows, macOS, and Linux.
